### 🧠 Featured Research

| | |
|---|---|
| **Project** | Forecast-Driven, QKD-Aware Proactive Routing |
| **Institution** | NIT Rourkela (under Prof. Sadananda Behera) |
| **Approach** | Hybrid GCN-BiLSTM traffic forecasting (~2.6M params) + DQN / Double DQN / Dueling DQN routing agents |
| **Dataset** | Real Abilene backbone traffic matrix — 132 flows, ~48K samples, chronological train/test splits (no data leakage) |
| **Result** | **99.8%** fewer simulated key-exhaustion events (621 vs. 325,817) · **97%** delivery ratio — best of 5 routing policies evaluated |
